# Matriks Kasus Uji (Test Case) — Endpoint Autentikasi (Auth)

Dokumen ini menyajikan seluruh skenario pengujian untuk endpoint autentikasi backend **Sistem Akademik TUP** dalam format tabel terstruktur.

---

## 1. Informasi Lingkungan & Konfigurasi Pengujian

| Parameter                 | Konfigurasi / Keterangan                                                         |
| :------------------------ | :------------------------------------------------------------------------------- |
| **Modul**                 | Autentikasi Pengguna (_Authentication Module_)                                   |
| **Base URL**              | `http://localhost:3000/api/auth`                                                 |
| **Format Data**           | `application/json`                                                               |
| **Mekanisme Autentikasi** | JSON Web Token (JWT) — `Authorization: Bearer <token>`                           |
| **Masa Berlaku Token**    | 1 Hari (`1d`)                                                                    |
| **Enkripsi Sandi**        | Bcrypt (Salt rounds = 10)                                                        |
| **Aturan Domain Email**   | Mahasiswa: `@student.telkomuniversity.ac.id`<br>Dosen: `@telkomuniversity.ac.id` |
| **Rate Limit**            | Maksimal 20 request per 15 menit per IP (`authRateLimiter`)                      |

| :------------------ | :---------------------------------------------------------------- | :-------------------------------------------------: | :---------------------------------------------------------------------------------------------------------------- | :---------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------: |
| **TC-AUTH-SEC-001** | Pengujian Rate Limiting Brute Force Auth (`authRateLimiter`)      | `POST /api/auth/login`<br>`POST /api/auth/register` | Kirim request sebanyak 21 kali secara simultan dari IP yang sama dalam jangka waktu < 15 menit                    | `429 Too Many Requests` | Request ke-1 s/d ke-20 diproses normal.<br>Request ke-21 mengembalikan:<br><pre>{<br> "success": false,<br> "message": "Terlalu banyak percobaan autentikasi. Silakan coba lagi setelah 15 menit."<br>}</pre> | _Pending_  |
| **TC-AUTH-SEC-002** | Pengujian Kebocoran Hash Kata Sandi (_Data Leakage Prevention_)   |                Seluruh endpoint auth                | Periksa respon body pada `register`, `login`, dan `user`                                                          |            -            | Respon JSON **tidak boleh** mengandung key `password`, hash password, salt, atau `deletedAt`.                                                                                                                 | _Pending_  |
| **TC-AUTH-SEC-003** | Pengujian Manipulasi Payload Token (_JWT Tampering / Escalation_) |                `GET /api/auth/user`                 | Ubah claim role di dalam JWT payload (misal dari `MAHASISWA` menjadi `ADMIN`) tanpa mere-sign dengan `JWT_SECRET` |     `403 Forbidden`     | <pre>{<br> "message": "Invalid token"<br>}</pre>Sistem memverifikasi signature kunci rahasia secara ketat.                                                                                                    | _Pending_  |
