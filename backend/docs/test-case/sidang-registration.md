# Matriks Kasus Uji (Test Case) — Endpoint Pendaftaran Sidang

Dokumen ini menyajikan spesifikasi kasus uji untuk endpoint **Pendaftaran Sidang** backend **Sistem Akademik TUP** dalam format tabel terstruktur beserta hasil eksekusi pengujian otomatis.

---

## 1. Informasi Lingkungan & Konfigurasi Pengujian

| Parameter                                         | Konfigurasi / Keterangan                                                                                                                                                                                                                                                                                                                                                                                                                        |
| :------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Modul**                                         | Pendaftaran Sidang Tugas Akhir (_Sidang Registration_)                                                                                                                                                                                                                                                                                                                                                                                          |
| **Base URL**                                      | `http://localhost:3000/api/sidang-registrations`                                                                                                                                                                                                                                                                                                                                                                                                |
| **Format Data**                                   | `application/json`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Mekanisme Autentikasi**                         | JSON Web Token (JWT) — `Authorization: Bearer <token>`                                                                                                                                                                                                                                                                                                                                                                                          |
| **Hak Akses Cek Kelompok Capstone**               | Terautentikasi seluruh role login (`ADMIN`, `DOSEN`, `MAHASISWA`)                                                                                                                                                                                                                                                                                                                                                                               |
| **Aturan Pencarian Kelompok Capstone**            | 1. Hanya mencari pendaftaran pada periode pendaftaran sidang yang aktif (`category: "pendaftaran"`, `isOpen: true`).<br>2. Hanya mencakup pendaftaran skema Capstone (`skemaSidang` atau `skemaSidangFinal` = `"Capstone"`).<br>3. Prioritas pencarian: cari kecocokan pada `judulTugasAkhirIndonesia` terlebih dahulu (_case-insensitive_ & _trimmed_). Jika kosong/tidak ditemukan, fallback mencari kecocokan pada `judulTugasAkhirInggris`. |
| **Aturan Sensor Data Mahasiswa (_Data Masking_)** | - Nama mahasiswa: Setiap kata disensor seluruh hurufnya kecuali huruf pertama (contoh: `Nizar Daffa Maulana` $\rightarrow$ `N**** D**** M******`).<br>- NIM: Disensor seluruh digitnya kecuali 3 digit terakhir (contoh: `1202200019` $\rightarrow$ `*******019`).                                                                                                                                                                              |
| **Standar Parameter**                             | Canonical parameter name `judul` (wajib, string minimal 1 karakter non-spasi). Tidak ada alias.                                                                                                                                                                                                                                                                                                                                                 |

---
