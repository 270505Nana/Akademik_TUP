# Matriks Kasus Uji (Test Case) — Endpoint Penjadwalan Sidang

Dokumen ini menyajikan seluruh spesifikasi kasus uji untuk endpoint **Penjadwalan Sidang** backend **Sistem Akademik TUP** dalam format tabel terstruktur.

---

## 1. Informasi Lingkungan & Konfigurasi Pengujian

| Parameter | Konfigurasi / Keterangan |
| :--- | :--- |
| **Modul** | Penjadwalan Sidang Tugas Akhir (*Penjadwalan Sidang*) |
| **Base URL** | `http://localhost:3000/api/penjadwalan-sidang` |
| **Format Data** | `application/json` (Kecuali endpoint export: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) |
| **Mekanisme Autentikasi** | JSON Web Token (JWT) — `Authorization: Bearer <token>` |
| **Hak Akses Daftar & Export** | `ADMIN` dan `DOSEN_KETUAKK` (Untuk Dosen Ketua KK, data difilter otomatis sesuai *Research Group* masing-masing) |
| **Hak Akses Set Penguji** | Khusus `DOSEN_KETUAKK` (`authorize("DOSEN_KETUAKK")`) |
| **Hak Akses Set Jadwal & Kunci** | Khusus `ADMIN` (`authorize("ADMIN")`) |
| **Hak Akses Konfirmasi Baca** | Khusus `MAHASISWA` pemilik pendaftaran (`authorize("MAHASISWA")`) |
| **Aturan Bentrok Jadwal** | Rentang waktu minimal 2 jam antar sidang untuk ruangan yang sama dan seluruh dosen terkait (Pembimbing 1, Pembimbing 2, Penguji 1, Penguji 2) |
| **Aturan Kunci / Publikasi** | Dosen penguji tidak dapat diubah apabila pendaftaran berstatus `isLocked: true` atau periode sidang berstatus `isPublished: true` |
| **Aturan Skema Capstone** | Mahasiswa dalam 1 kelompok Capstone memiliki judul tugas akhir yang sama (perbandingan *case-insensitive* & *trimmed* pada judul Indonesia atau judul Inggris). Sesama kelompok Capstone diperbolehkan dijadwalkan pada waktu, ruangan, dosen pembimbing, dan dosen penguji yang sama. Jika judul berbeda, maka dianggap beda kelompok dan wajib memenuhi aturan jeda minimal 2 jam tanpa bentrok ruangan/dosen. |
